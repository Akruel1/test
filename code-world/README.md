## 🎮 О проекте

**CodeWorld** — это современный веб-сайт в игровом формате, где всё взаимодействие пользователя с миром, окружением и персонажем осуществляется исключительно через программирование.

### Ключевые особенности:

- 🎯 **Управление через код** — никаких кнопок, только программирование
- 💻 **Мультиязычность** — поддержка JavaScript и Python
- 🎨 **Пиксельная графика** — современный неоновый стиль
- 📚 **Обучающие уровни** — от простого к сложному
- 🏆 **Система достижений** — мотивация и прогресс
- 💾 **Сохранение прогресса** — локальное хранилище

## 🚀 Запуск

### Локальный запуск

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd code-world
```

2. Откройте `index.html` в браузере или используйте локальный сервер:
```bash
# С помощью Python
python -m http.server 8000

# Или с помощью Node.js
npx serve .
```

3. Откройте http://localhost:8000 в браузере

### Требования

- Современный браузер (Chrome, Firefox, Safari, Edge)
- JavaScript включен

## 📖 API Документация

### Движение

```javascript
await moveUp()      // Двигаться вверх
await moveDown()    // Двигаться вниз
await moveLeft()    // Двигаться влево
await moveRight()   // Двигаться вправо

// Сокращённая форма
await up()
await down()
await left()
await right()

// Двигаться на N шагов
await move('right', 5)
```

### Действия

```javascript
await collect()     // Собрать предмет на текущей позиции
await interact()    // Взаимодействовать с NPC
await wait(1000)    // Подождать 1000 мс
say("Привет!")      // Сказать сообщение
```

### Информация о мире

```javascript
getPosition()       // Получить {x, y} позицию игрока
getInventory()      // Получить содержимое инвентаря
hasItem('gem')      // Проверить наличие предмета
getPoints()         // Получить количество очков

canMove('right')    // Можно ли двигаться в направлении
look()              // Информация об окружении
lookAt(x, y)        // Информация о конкретной позиции
```

### Вспомогательные функции

```javascript
log("сообщение")    // Вывод в консоль

// Повторить действие N раз
await repeat(5, async (i) => {
    await moveRight()
})
```

## 🏆 Система достижений

- **Первые шаги** — Выполни первую программу
- **Коллекционер** — Собери 10 предметов
- **Мастер циклов** — Используй цикл для сбора 5 предметов
- **Безупречный код** — Пройди уровень без ошибок
- **Мастер CodeWorld** — Пройди все уровни
- И многие другие...

## 🎯 Примеры кода

### JavaScript

```javascript
// Собрать все монеты в ряд
for (let i = 0; i < 3; i++) {
    await moveRight();
    await collect();
}
```

### Python

```python
# Собрать все монеты в ряд
for i in range(3):
    await moveRight()
    await collect()
```

### Использование условий

```javascript
// Собирать только монеты
for (let i = 0; i < 5; i++) {
    await moveRight();
    
    const info = look();
    if (info.here.object === 'coin') {
        await collect();
    }
}
```
