# Neon Codeworld Prototype

This repository contains a single-page prototype for a programmable game
website. The experience includes a loading sequence, a short onboarding
presentation, and a game-like interface where users interact with the world
only through code.

## Run

Open `index.html` in a browser to launch the experience.

## Features

- Pixel-inspired neon UI with animated loading and intro screens
- Game field rendered on canvas with dynamic objects
- Multi-language code console (Python, Java, C++)
- Event log and in-world error feedback
- Local progress saving and simple achievements
