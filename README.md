# CodeForge World

Игровой веб-сайт, где единственный способ взаимодействия с миром — программирование.

## Возможности

- пиксельный загрузочный экран и интро-презентация
- разделение на игровое поле, редактор кода и панель событий
- поддержка Python, Java и C++ через безопасный интерпретатор команд
- игровые реакции на ошибки кода
- задания, достижения и сохранение прогресса в браузере
- адаптивный футуристичный интерфейс

## Запуск

Откройте `index.html` в браузере. Никакой сборки не требуется.

## Использование

1. Выберите язык программирования.
2. Введите команды в редакторе (например, `move_right(3)` для Python).
3. Нажмите **Запустить** и наблюдайте реакцию мира.

Прогресс и достижения сохраняются в `localStorage` браузера.
