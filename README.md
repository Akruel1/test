# CODEWORLD — программируемый игровой веб‑мир

MVP прототип: современный “игровой” веб‑интерфейс, где миром можно управлять **только через код**.

## Что уже есть

- **Загрузочный экран** в пиксель/неон стиле + короткая интро‑презентация
- **Основной интерфейс**: игровое поле (canvas), встроенный редактор кода (Monaco), логи/ошибки как “события мира”
- **Переключение языков**: Python / Java / C++
  - Python: запускается в **песочнице WebWorker + Pyodide (CDN)**
  - Java/C++: пока заглушки (архитектура готова для расширения)
- **Сохранение прогресса** (tutorial + код + достижения) в `localStorage`

## Запуск локально

```bash
cd web
npm install
npm run dev
```

## Сборка

```bash
cd web
npm run build
```
