## 📖 О проекте

**CodeWorld** — это интерактивный игровой веб-сайт, где единственный способ взаимодействия с миром — программирование. Управляйте персонажем, решайте головоломки и исследуйте виртуальный мир с помощью кода!

### ✨ Особенности

- 🎮 **Игровой формат** — учитесь программировать через увлекательную игру
- 💻 **Встроенный редактор кода** — пишите и запускайте код прямо в браузере
- 🌐 **Мультиязычность** — поддержка Python, JavaScript, Java, C++
- 🎨 **Современный дизайн** — пиксельная графика с неоновыми эффектами
- 📊 **Система прогресса** — уровни, достижения, очки
- 🎯 **10 уровней** — от простых до сложных головоломок

## 🚀 Быстрый старт

### Локальный запуск

1. **Клонируйте репозиторий:**
```bash
git clone <repository-url>
cd codeworld
```

2. **Запустите локальный сервер:**

С Python:
```bash
python -m http.server 8000
```

Или с Node.js:
```bash
npx serve .
```

3. **Откройте в браузере:**
```
http://localhost:8000
```

### Онлайн

Просто откройте `index.html` в современном браузере (рекомендуется Chrome, Firefox, Edge).

## 🎮 Как играть

### Базовое управление персонажем

```python
# Перемещение в направлении (right, left, up, down)
player.move("right", 3)  # переместиться вправо на 3 клетки

# Прыжок через препятствия
player.jump("right", 2)  # перепрыгнуть 2 клетки вправо

# Взаимодействие с объектами
player.interact()  # активировать переключатель/поговорить с NPC

# Ожидание
player.wait(1)  # подождать 1 секунду
```

### Информация о мире

```python
# Получить позицию игрока
pos = player.getPosition()
print(pos["x"], pos["y"])

# Проверить проходимость клетки
if world.canMoveTo(5, 3):
    player.moveTo(5, 3)

# Получить позицию выхода
exit = world.getExitPosition()

# Количество оставшихся кристаллов
crystals = world.getRemainingCrystals()
```

### Пример использования циклов

```python
# Собрать кристаллы в ряд
for i in range(5):
    player.move("right", 2)
    player.collect()
```

### Пример с условиями

```python
# Умное перемещение
pos = player.getPosition()
exit = world.getExitPosition()

if pos["x"] < exit["x"]:
    player.move("right", exit["x"] - pos["x"])
if pos["y"] < exit["y"]:
    player.move("down", exit["y"] - pos["y"])
```

## 🔧 Разработка

### Добавление нового уровня

1. Откройте `src/js/levels/level-data.js`
2. Добавьте новый объект уровня в массив `levels`:

```javascript
{
    id: 11,
    name: 'Название уровня',
    difficulty: 3,
    objective: 'Цель уровня',
    width: 15,
    height: 10,
    playerStart: { x: 1, y: 1 },
    exit: { x: 13, y: 8 },
    map: [
        '###############',
        '#.............#',
        // ...
    ],
    objects: [
        { type: 'crystal', x: 5, y: 3 },
    ],
    starterCode: `# Начальный код`,
    hints: ['Подсказка 1', 'Подсказка 2'],
    requireAllCrystals: true
}
```

### Добавление нового достижения

1. Откройте `src/js/levels/achievements.js`
2. Добавьте новый объект достижения:

```javascript
{
    id: 'unique_id',
    name: 'Название',
    description: 'Описание достижения',
    icon: '🎯',
    condition: (stats, levelStats) => stats.someValue >= 100
}
```
