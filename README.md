# Neon Byte World — прототип

Игровой веб‑мир, где **единственный способ взаимодействия** с персонажем и окружением — **программирование**.  
Пользователь пишет код (Python/Java/C++), запускает программу и наблюдает, как мир реагирует: движения, события, “глитчи” при ошибках, прогресс по заданиям.

## Запуск локально

Проект находится в папке `web/`.

```bash
cd web
npm install
npm run dev
```

## Что уже реализовано (MVP)

- **загрузочный экран** в стиле пиксель‑неон
- **короткая интро‑презентация** (автопереход/пропуск)
- **основной интерфейс**: мир (Canvas) + редактор кода + панель событий
- **переключение языков**: Python / Java / C++
- **безопасное исполнение**: ограниченный поддерживаемый поднабор команд (интерпретация без выполнения произвольного кода)
- **уровень‑обучение** с целями и локальным сохранением прогресса/кода/достижений
