# Neon Byte World (frontend)

Прототип игрового веб‑мира “управление только кодом”.

## Запуск

```bash
npm install
npm run dev
```

## Поддерживаемые команды (прототип)

- `move(dx, dy)` / `move(dx, dy);` — шаг на клетку (dx/dy: -1..1)
- `say("text")` / `say("text");` — сообщение как событие мира
- `wait(n)` / `wait(n);` — “пауза” (игровые тики)
- циклы:
  - Python: `for i in range(n):`
  - Java/C++: `for (int i = 0; i < n; i++) { ... }`

## Архитектура (MVP)

- `src/game/*` — состояние мира, уровни, движок команд, локальное сохранение
- `src/vm/*` — компиляция/интерпретация ограниченного поднабора Python/Java/C++
- `src/ui/*` — загрузка, интро, основной интерфейс (Canvas + редактор + логи)
